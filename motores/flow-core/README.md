
# 📦 FlowCore

> "El flujo nunca se detiene; solo cambia de estado."

---

FlowCore es el motor base de Gudo Labs.

Su objetivo es representar sistemas donde:

- Los eventos modifican estados.
- Las decisiones generan consecuencias.
- Las restricciones interactúan.
- Los ciclos producen aprendizaje.

---

El motor no pertenece a una industria.

Pertenece al concepto de flujo.
